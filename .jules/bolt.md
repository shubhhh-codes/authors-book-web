## 2024-05-18 - [Optimized ProductCard Component Rendering]
**Learning:** React Server Components in Next.js App router shouldn't be wrapped in React.memo if they are true Server Components. However, since the `ProductCard` component is imported by `app/shop/page.tsx` and `app/product/[id]/page.tsx` which both have `"use client"` directives at the top, the `ProductCard` becomes a Client Component as part of that tree. Therefore, `React.memo` is valid and beneficial here as these list components re-render based on client-side state (like search params, pagination, and cart state).
**Action:** Always check the module graph for `"use client"` directives before assuming a component is a Server Component. `React.memo` is highly effective for list items in Client Component trees.
